# 段階1 結果：立方体 1 個を鍋に入れる（ACT）

手順は [step1_howto.md](step1_howto.md)。SageMaker Studio で実行した結果。

## 条件

| 項目 | 内容 |
|---|---|
| 物体 | 25mm 角の立方体 1 個（オレンジ）。ロボット前方の半径 7cm の円内に、ランダムな位置・向きで置く |
| 鍋 | (0.20, 0.20) に固定、内径 11cm・高さ 5cm |
| ポリシーの入力 | 俯瞰カメラ・手首カメラ画像（224×224）、6 関節の角度 |
| ポリシーの出力 | 6 関節の目標角度（25Hz） |
| モデル | ACT（LeRobot 0.6.1）、約 5,200 万パラメータ |

## 1. データ生成（ml.c5.9xlarge、36 プロセス）

| 項目 | 値 |
|---|---|
| 成功エピソード | 300（51,087 フレーム） |
| エキスパートの成功率 | 99.3%（302 回中 300 回。失敗は運搬中の落下 1、掴み損ね 1） |
| 所要時間 | 生成 5 分 25 秒 + 統合 1 分 |

## 2. 学習（ml.g5.xlarge、NVIDIA A10G）

| 項目 | 値 |
|---|---|
| ステップ数 | 40,000（バッチ 16、約 12.5 エポック） |
| 所要時間 | 50 分 56 秒（13.1 ステップ/秒） |
| loss | 0.70（2,000 ステップ）→ 0.050（40,000 ステップ） |
| l1_loss（行動の予測誤差） | 0.145 → 0.048 |
| GPU メモリ | 1.6GB |

## 3. 評価（学習に使っていない配置 50 通り、seed 100000〜100049）

| 結果 | 回数 | 割合 |
|---|---|---|
| **成功（鍋に入った）** | **41** | **82%** |
| 掴めなかった（not_grasped） | 6 | 12% |
| 持ち上げたが鍋に入らなかった（missed_pot） | 3 | 6% |

- 成功したエピソードの平均ステップ数は 147（約 5.9 秒。鍋に入ってから 1 秒で打ち切り）。
- 評価は ml.g5.xlarge の CPU で 8 プロセス、約 3 分。

## 考察（暫定）

- 物体の位置を入力に使わず、カメラ画像だけで 82% の成功率に達した。お手本（エキスパート）の 99% には届いていない。
- 失敗の 3 分の 2 は把持の段階で起きている。今の設定では、予測した 50 ステップ（2 秒）分の行動を
  途中で見直さずに実行するため、把持直前の小さなずれを修正できていない可能性がある。
- 次に確かめること（学習し直さずに評価の設定だけで試せる）:
  - 行動を見直す間隔を短くする（`--n-action-steps 10`）
  - ACT の時間的アンサンブル（`--temporal-ensemble 0.01`、毎ステップ予測して重み付き平均）
  - チェックポイント（10,000〜40,000 ステップ）による違い
